# SeihouModule

- [agent-gitignore](agent-gitignore.md) - Ensure .claude/, .agents/, and CLAUDE.local.md are in .gitignore
- [claude-gitignore](claude-gitignore.md) - Ensure .claude/ and CLAUDE.local.md are in .gitignore
- [claude-skill-link](claude-skill-link.md) - Symlink a Claude skill from claude/skills/ into .claude/skills/
- [exec-plan-digest](exec-plan-digest.md) - Claude skill that emits a standardized JSON digest of ExecPlans — status, progress, discoveries, decisions, commit-trailer coverage, and prioritized findings for things a human skimming would miss
- [exec-plan](exec-plan.md) - Claude skill for creating and managing execution plans (ExecPlans)
- [link-skill](link-skill.md) - Symlink a skill from claude/skills/ into both .claude/skills/ and .agents/skills/
- [master-plan-digest](master-plan-digest.md) - Claude skill that emits a standardized JSON digest of MasterPlans — registry, dependency graph (ready/blocked/critical path), per-child exec-plan digests, trailer coverage, and coordination findings (registry drift, cascade gaps, integration-point violations)
- [master-plan](master-plan.md) - Claude skill for creating and managing master plans (MasterPlans) — coordination documents that decompose large initiatives into multiple ExecPlans
- [update-docs](update-docs.md) - Claude skill to update project documentation after code changes
