# SeihouPrompt

- [fix-prelude-import-conflicts](fix-prelude-import-conflicts.md) - Reusable agent-session prompt that fixes custom-prelude import-conflict violations in a Haskell repo — hide clashing names from the prelude import (never the other import) and never qualify operators. Tunable per project via first-class guidance blocks (prelude module, build tool/command, free-form guidance).
